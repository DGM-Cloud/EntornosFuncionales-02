# Entornos Funcionales — prototipo web

Prototipo frontend de alta fidelidad preparado para una presentación comercial. Está construido desde cero con React y Vite; la web pública vigente se utilizó únicamente como fuente de contenido institucional, datos de contacto e imágenes.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Alcance de la demo

- Cinco vistas: Inicio, Proyectos, Soluciones, Nosotros y Contacto.
- Navegación responsive, filtros de proyectos, visor de imágenes y acordeón de soluciones.
- Contacto directo y formulario conectado a WhatsApp.
- Carrusel visual preparado para incorporar empresas y clientes autorizados.
- Los nombres de clientes, ubicaciones y datos de obra que no estaban confirmados se omitieron.
- Las etiquetas editoriales de fotografías son descriptivas y deben validarse con Entornos Funcionales antes de publicar.
- Los nombres del carrusel empresarial son placeholders visibles de presentación y no representan clientes confirmados.

## Despliegue

El sitio se publica automáticamente en GitHub Pages cada vez que se actualiza la rama `main`:

<https://dgm-cloud.github.io/EntornosFuncionales-02/>

El flujo de publicación compila la aplicación, conserva la navegación de las cinco vistas y genera un respaldo para abrir o recargar rutas internas directamente.
